#Projetos Java - Recode (Transforma Futuros)

Repositório destinado ao armazenamento de exercícios e aplicações desenvolvidas durante o módulo de **Java e Orientação a Objetos** do programa **Transforma Futuros**, oferecido pela **Recode**.

---

## Conteúdos e Tecnologias Aprendidas

Neste repositório, estão reunidos desde códigos de lógica fundamental até aplicações completas integradas com banco de dados e APIs REST:

* **Lógica e Programação Orientada a Objetos (POO):**
  * Conceitos fundamentais de Java (sintaxe, arrays, coleções).
  * Aplicação de **Encapsulamento**, Herança e Polimorfismo para escrever códigos mais limpos, seguros e reutilizáveis.

* **Persistência de Dados & Banco de Dados:**
  * Manipulação de bancos de dados relacionais (MySQL).
  * Gerenciamento de servidores locais utilizando **XAMPP**.
  * Mapeamento Objeto-Relacional (ORM) com **Jakarta Persistence / Hibernate (JPA)**.

* **Desenvolvimento Web & Produtividade com Spring:**
  * Uso do **Spring Initializr** para acelerar o setup inicial de novos projetos e gerenciar dependências.
  * Criação de endpoints RESTful com **Spring Boot**.

* **Testes de API:**
  * Teste e validação das requisições HTTP (GET, POST, PUT, DELETE) e rotas utilizando o **Postman**.

---

## Estrutura de Projetos

* `aula/` - Exercícios iniciais de sintaxe e lógica.
* `ExemplosArray/` - Manipulação de arrays e coleções em Java.
* `BancoDeDados/` - Scripts e conexões fundamentais com banco de dados.
* `crud/` - Aplicação completa de gerenciamento (CRUD) criada com Spring Boot, JPA/Hibernate e MySQL.

---

## Tecnologias Utilizadas

* **Linguagem:** Java 21+
* **Framework:** Spring Boot
* **IDE:** Eclipse IDE
* **Banco de Dados:** MySQL / XAMPP
* **Ferramentas de Teste:** Postman
